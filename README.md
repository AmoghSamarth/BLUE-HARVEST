# 🐟 Blue Harvest — Responsive Mobile Login Application

> **Count fish spawn live with your camera.**  
> Blue Harvest is a mobile web application designed to help fish farmers count fish spawn and fry directly using computer vision.

---

## 🌟 Features

- **Exact Reference Match:** Pixel-perfect implementation of the Blue Harvest mobile login screen based on the design specification.
- **Organic Aesthetics:** Multi-layered oceanic waves, circular blue fish branding badge, and sunken neumorphic inputs with ergonomic touch targets.
- **Interactive Controls:** Toggleable password visibility with dedicated floating pill button, Google OAuth CTA, and registration flow.
- **Responsive Design (`/responsive-design` & `/responsive-art-direction`):**
  - **Mobile Screens (≤480px):** Full-bleed edge-to-edge native mobile app experience with dynamic viewport units (`100dvh`), zero horizontal scroll overflow, and safe-area padding.
  - **Desktop / Tablet Screens (>480px):** Sits centered as a sleek, modern app container against an ambient canvas.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

Open your browser at:
```
http://localhost:5173/
```

### 3. Production Build
```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Vanilla CSS with custom tokens & neumorphic lighting effects
- **Icons:** Lucide React
- **Typography:** Nunito via Google Fonts
